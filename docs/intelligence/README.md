# SueLr Studio Intelligence Program

This directory contains the public execution plan for replacing the current immature Agent implementation with a broader Agent + Skills + Knowledge Base system.

Start here:

- `00-master-plan.md`: product vision, target architecture, ownership boundaries, and rollout principles
- `01-phased-execution-plan.md`: implementation phases, scope, dependencies, risks, and exit criteria
- `02-acceptance-plan.md`: per-phase acceptance plan and total program acceptance gate
- `03-legacy-agent-replacement-plan.md`: migration path from `backend/src/modules/agent/` to the new intelligence runtime
- `04-knowledge-base-taxonomy.md`: detailed knowledge categories, write policies, retrieval rules, and storage evolution
- `05-design-team-operating-model.md`: Agent roles, team templates, collaboration modes, and workflow-building behavior
- `06-governance-and-gates.md`: documentation gates, coding constraints, safety policy, and verification checklist

The plan is intentionally staged. SueLr Studio already has workflow execution, provider routing, generated media storage, settings, memory, and agent routes. The intelligence program must build on those facts instead of bypassing them.
