# SueLr Studio 智能工作室计划（中文版）

这一套文档是给产品决策和日常跟进看的中文版本。英文版放在 `docs/intelligence/` 根目录，偏工程执行、验收和门禁引用；中文版放在 `docs/intelligence/zh/`，偏完整理解、路线规划和阶段管理。

建议阅读顺序：

- `00-总计划方案.md`
- `01-分阶段执行方案.md`
- `02-分阶段验收与总验收计划.md`
- `03-现有Agent替换计划.md`
- `04-知识库分类与治理方案.md`
- `05-设计团队与工作流自动搭建方案.md`
- `06-治理门禁与推进规则.md`

核心目标：

把 SueLr Studio 从“有聊天、有工作流、有图片/视频生成”的工具，升级成一个本地优先的 AI 设计工作室操作系统。用户提出设计目标后，系统可以组建设计团队、拆解任务、搭建工作流、执行生产、评审返工、沉淀知识，并逐步替换当前不成熟的 Agent 体系。
