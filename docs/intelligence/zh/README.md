# SueLr Studio Intelligence 计划

这一套文档记录 SueLr Studio 新 Agent 体系的产品方向、阶段计划、验收标准和治理规则。

当前方向已经调整：不再把“AI 设计团队”或“工作流助手”作为主产品形态。新的目标是一个全局对话式 Agent：用户通过对话提出需求，Agent 使用 LLM planner 理解任务、选择工具、执行工具，并把最终结果交付给用户。工作流搭建、编辑、运行、诊断只是 Agent 可调用的工具之一。

## 一句话目标

把 SueLr Studio 从分散的聊天、图像、视频、工作流工具，升级成一个本地优先的对话式 AI 工作系统。用户只需要说明要完成什么，Agent 负责规划、调用工具、执行、复盘和交付结果。

## 当前优先级

1. 先把入口形态统一为全局对话式 Agent。
2. 在 Agent 窗口内选择 Planner 模型，不新增设置页入口。
3. 接入 LLM planner，让模型基于可用节点、知识库和工具定义产出结构化计划。
4. 把工作流搭建、编辑、运行、诊断纳入 Agent 工具，而不是单独做“工作流助手”。
5. 后续再扩展图片、视频、文本、文件、资产、知识写入等工具。
