# 治理门禁与推进规则

## 公开文档规则

智能工作室计划的公开文档允许放在：

```text
docs/intelligence/
docs/intelligence/zh/
```

这里放长期有效的产品方案、架构方案、执行计划、验收计划。

不要放：

- 临时草稿
- 私人笔记
- 未定方案
- 每周随手记录

这类内容应该放 `.private-docs/`。

## 代码归属规则

后端新智能体系：

```text
backend/src/modules/intelligence/
```

前端：

```text
src/domains/chat/
src/domains/workflow/
src/features/settings/
src/shared/api/
```

禁止把领域组件放进：

```text
src/components/
```

## 工作流安全规则

禁止：

- 模型直接修改 React Flow 状态
- 模型直接写最终工作流 JSON 并落库
- 未确认就执行生成的工作流
- 知识库静默选择工作流
- 知识库静默填写工作流输入

必须：

- 先生成 WorkflowDraft
- 编译
- 校验
- 预览
- 用户确认
- 再保存或执行

## 本地 MVP 门禁

第一实现门禁是 `desktop` 和 `local-web` 的完整本地智能工作室闭环：

- Agent Runtime 不依赖 `server-web`
- Workflow Architect 能在本地创建和校验草案
- 用户确认后的工作流走现有本地后端执行服务
- Studio Brain 默认使用本地个人/项目知识
- 设计团队角色能在本地计划、评审、要求返工
- 资产输出继续使用现有 App URL 协议
- 旧 Agent 替换先在本地验收完成

这个门禁通过前，不把服务器同步、公共知识库、多用户 Agent 作为实现前置条件。

## 服务器迁移门禁

只有本地 MVP 总验收通过后，才允许进入 `server-web` 迁移。

迁移设计必须先覆盖：

- 用户和工作区隔离
- Agent 调用消耗当前用户 provider 或工作区授权额度
- 私有、工作区、公共知识作用域
- 共享知识贡献、审核、通过、拒绝
- 数据导入导出和迁移回滚
- 同步冲突处理
- 继续支持本地独立使用

## 知识库治理规则

每条知识必须有：

- 类型
- 来源
- 作用域
- 置信度或证据
- 创建/更新时间

禁止写入：

- 原始 chain-of-thought
- 大 base64
- 临时 debug 噪音
- 绝对文件路径
- 未确认的品牌规则
- 未确认的项目约束

## Skill 治理规则

每个 Skill 必须定义：

- 输入 schema
- 输出 schema
- 副作用等级
- 是否需要审批
- 超时或取消策略
- 日志策略

副作用等级：

```text
read          只读
suggest       只建议
writeDraft    写草案
write         持久写入
execute       执行任务
external      外部调用
destructive   删除/覆盖
```

默认审批：

- `read`：不需要
- `suggest`：不需要
- `writeDraft`：不需要，应用到当前工作需确认
- `write`：持久写入一般需要
- `execute`：默认需要
- `external`：需要用户开启或确认
- `destructive`：必须确认

## 校验命令

文档变更：

```bash
npm run check:docs
npm run check:encoding
```

后端智能模块变更：

```bash
npm run typecheck
npm run test --prefix backend
npm run check:encoding
```

前端智能 UI 变更：

```bash
npm run typecheck
npm run test:unit
npm run build
```

工作流行为变更：

```bash
npm run check:workflow-store
npm run typecheck
npm run test --prefix backend
npm run test:unit
```

重大切换前：

```bash
npm run check
```

## 推进主分支前检查

推进主分支前必须确认：

- 当前工作区没有未解释的用户改动
- 文档门禁通过
- 编码检查通过
- 新增文档在允许目录
- 没有修改 Electron CommonJS 规则
- 没有改端口
- 没有硬编码运行时路径
- 没有把 React Flow 状态移入 Zustand
- 没有把领域组件放进 `src/components/`
