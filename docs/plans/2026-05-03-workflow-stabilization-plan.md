# Workflow Stabilization Implementation Plan

## 目标

基于仓库审计结果，分阶段完成 SueLr Studio 的结构收口、契约统一、状态拆分与工程治理，恢复项目的可持续开发能力。

## 执行原则

- 每周只聚焦一个主风险面
- 先盘点边界，再做迁移，最后才删旧层
- 每周都必须产出可复核结果，不能只停留在口头分析
- 每周结束至少执行一轮验证命令，除非该周明确只处理文档

## 推荐执行策略

推荐采用“稳态推进”：

- 每周只收一个口
- 优先保证可运行、可回滚、可验证
- 不并行推进多个高风险结构改造面

## 每周固定检查清单

- 本周是否只针对一个主问题面
- 本周是否明确了保留、迁移、删除对象
- 本周是否记录了唯一入口或唯一契约
- 本周是否同步更新了 `docs`
- 本周是否完成至少一轮验证命令

## 阶段完成定义

- 完成：已有代码 / 文档 / 测试 / 说明的可验证结果
- 部分完成：分析完成，但迁移或验证尚未闭环
- 未完成：只有口头结论，尚无文档或执行产物
