# 工作流节点重做清单

## 辅助提示词

### 移除前的功能

- [x] 画布卡片显示当前工具和配置摘要，打开独立工作台切换工具、编辑参数和预览实时提示词。工作台预览使用本地基础描述，实际运行时可能采用上游文本。
- [x] 可选的上游基础提示词输入、本地基础画面描述及字符串提示词输出。运行时优先用非空的上游文本，否则使用本地描述，再与当前工具的规则拼接。生成过程由模板完成，无模型调用，也无图像输入端口。
- [x] 三种提示词风格，分别为通用、GPT-image-2 和 Nano Banana。按工具输出叙述式指令、简洁指令或结构化参数。
- [x] 转换视角支持调整现有图或新生成图片。编辑现有图时可旋转主体并锁定场景，或移动摄像机并重建透视。支持焦距、距离、方位角、高度、位置、目标和景别，并针对背面、俯拍和仰拍补充构图约束。
- [x] 视角和灯光工具提供 3D 场景参考。可环绕、缩放，拖动相机或灯光的位置及轴向手柄，联动配置和输出。
- [x] 调整光照支持新增光线和重塑光线。最多配置六盏面光、方向光或聚光灯，可调整类型、名称、颜色、强度、位置和方向。
- [x] 分镜支持横版 4／6／9 格、竖版 3／6／9 格或自定义 1–12 镜头及整图比例。可选择写实、商业广告、动画、草图、产品演示、社媒、电商或自定义风格。每镜可填时长、内容和备注，可控制连续性、画面文字和镜头编号，并预览白底网格。
- [x] 三视图和参考图支持标准三视图、三视图加细节、角色参考、产品参考和自定义模板。主体可选角色、产品或物件。可管理内容块的类型、说明、权重、位置、尺寸和一致性约束，并预览版式。
- [x] 配置归一化可补齐默认参数，并兼容旧灯光方向、旧分镜动作与备注字段、旧版自定义分镜和版式数据。

### 建议增加

- [ ] 让预览纳入真实上游文本，标出每段来源。支持复制、手动覆盖、变量占位符、正负提示词及预设导入导出。
- [ ] 将模型格式做成独立适配器，提供字段校验和样例预览。支持多个工具组合，允许调整顺序并提示冲突约束。
- [ ] 增加参考素材输入及身份、构图、色彩等参考角色。支持可选的图像理解或试生成，并展示费用、耗时和生成版本。
- [ ] 增加镜头与灯组预设、可直接输入的目标点、灯光柔硬度及色温。为 3D 交互提供键盘或数值编辑方式。
- [ ] 支持分镜拖拽重排、复制、总时长和逐镜导出。为版式增加网格吸附、对齐、留白和重叠校验，并提供结构化结果供下游消费。

## 素材处理

### 移除前的功能

- [x] 使用统一的必填素材输入和结果输出，可接入多条上游连线、单值或嵌套数组。处理前展开数组、去除空值，并从含 URL 的对象提取地址。
- [x] 支持自动识别、文本和图像。手动选择时只处理匹配项。自动识别要求所有有效项属于同一可识别类型，混合或未知素材会报错。
- [x] 支持仅拆分、仅逐项、拆分后逐项。至少启用一项，默认只拆分。禁用节点时，编辑器的执行图支持透传输入。
- [x] 文本按字面分隔符拆分，默认换行，每段原文最多输出 1–9 项，默认 2 项。最后一项保留余下内容，移除边界换行和空结果。
- [x] 图像支持 1–3 行及 1–3 列，默认 3×3。可处理运行时可访问的本地媒体、远程 HTTP(S) 图片和 Base64 图片。拆分前应用 EXIF 方向，分摊余数像素，按从上到下、从左到右输出。优先尝试原格式，失败时回退 PNG。网格超过像素尺寸会报错。
- [x] 仅拆分时下游一次接收结果数组。逐项时每项独立运行下游，并按工作流并发配置调度。编辑器和运行时限制同一执行路径只启用一个逐项节点，独立分支可以分别逐项。
- [x] 画布卡片使用 IO 风格预览有效输入或最新结果，保留文本换行并显示实际缩略图。可调整底部面板，查看采纳和忽略数量，并配置类型、处理模式及对应的拆分参数。
- [x] 图像分块使用临时运行资产，可经过多个下游节点。运行时预览和持久化文件分开管理。完成、失败或取消后可继续预览，下一次运行同一工作流时释放，启动时清理残留。逐项事件携带来源、序号和总数，编辑器聚合结果并更新状态。下游 IO 还可开启迭代汇总，逐轮累积结果。

### 建议增加

- [ ] 统一预览和后端的素材分类，优先依据明确的类型和 MIME。覆盖无扩展名图片、带查询参数的 URL、视频 URL 和浏览器 Blob。展示每个跳过项的原因。
- [ ] 明确拆分、逐项与汇总的输出契约。定义并行分支汇合行为，避免旧实现中两个逐项分支共享下游时互相等待。支持按输入顺序汇总，附带素材索引、原始来源、行列及处理状态。
- [ ] 支持逐项并发上限、失败后继续、单项重试、取消、进度和失败汇总。对大量素材预估任务数，允许试跑前几项。
- [ ] 文本支持正则、空行、固定字数或语义分段，增加去重、过滤、保留分隔符与样例预览。明确输出上限按单输入还是整个批次生效。
- [ ] 图像支持可视化裁切预览、自定义边界、重叠和留白、裁去分镜边框、输出尺寸与格式。提供显式保存分块和可配置的临时资产保留周期。
- [ ] 按需求扩展表格行、JSON 数组、PDF 页、视频帧或音频片段，并为每类素材提供稳定的输入和结果结构。
