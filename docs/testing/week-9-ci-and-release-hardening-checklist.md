# Week 9 CI And Release Hardening Checklist

## 目标

确认 Week 9 已经把现有质量门禁、环境基线与发布回滚说明收口为可执行的工程基线。

## 自动验证

- [x] 项目仓库已接入远程 CI
- [x] CI 已在 push 与 pull request 时自动执行
- [x] CI 已配置执行 `npm run check`
- [x] CI 失败时能在 GitHub Actions 中定位失败步骤
- [x] 项目已声明统一 Node 版本
- [x] 项目已补齐 `.env.example`

## 人工复核

- [x] 已按当前文档完成依赖安装与本地拉起
- [x] 已按文档核对本地环境变量基线与启动方式
- [x] 已梳理构建、部署与运行入口
- [x] 已补齐回滚步骤说明
- [x] 最小手工冒烟已完成

## 通过标准

满足以下条件即可认为 Week 9 完成：

1. 质量门禁已经从“本地命令”提升为“远程自动执行”
2. Node、env、启动方式与依赖安装有单一可信说明
3. 部署与回滚不再依赖口头记忆
4. 发布前最小人工确认项已经固定
