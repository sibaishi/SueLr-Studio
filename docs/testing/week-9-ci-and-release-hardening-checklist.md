# Week 9 CI And Release Hardening Checklist

## 目标

确认 Week 9 已经把现有质量门禁、环境基线与发布回滚说明收口为可执行的工程基线。

## 自动验证

- [x] 项目仓库已接入远程 CI
- [x] CI 已在 push 或 PR 时自动执行
- [x] CI 已配置执行 `npm run check`
- [ ] CI 失败时能够明确返回失败步骤
- [x] 项目已声明统一 Node 版本
- [x] 项目已补齐 `.env.example`

## 人工复核

- [ ] 按文档从零安装依赖并拉起前后端，确认步骤完整可执行
- [ ] 按文档检查本地环境变量配置，确认关键项没有缺失
- [x] 按部署文档梳理一次构建与发布路径，确认没有口头步骤
- [x] 按回滚文档模拟一次失败回退流程，确认步骤清楚且顺序合理
- [ ] 执行一次最小冒烟：打开工作流页面、进入设置页、运行一条最小工作流

## 通过标准

满足以下条件即可认为 Week 9 完成：

1. 质量门禁已经从“本地命令”提升为“远程自动执行”
2. 运行环境与配置基线有单一可信说明
3. 发布与回滚不再依赖个人记忆
4. 最小人工冒烟流程可作为发布前固定补充项
