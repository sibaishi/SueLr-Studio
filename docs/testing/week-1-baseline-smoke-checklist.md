# Week 1 Baseline Smoke Checklist

## 目的

用于验证基线治理没有破坏当前项目的基本启动、构建与测试能力。

## 执行前检查

- 根目录与 `backend/` 依赖已安装。
- 本地不存在必须提交的运行时目录变更。
- `.env` 如有使用，内容来自本地，不进入版本控制。

## 自动检查

### 1. TypeScript 类型检查

运行：

```bash
cmd /c npx tsc --noEmit
```

预期：

- 命令成功退出。
- 无新的类型错误。

### 2. 前端构建

运行：

```bash
cmd /c npm run build
```

预期：

- 成功产出前端构建结果。
- 无新增构建错误。

### 3. 后端测试

运行：

```bash
cmd /c npm test
```

预期：

- 测试通过。
- 无新增失败用例。

## 手工检查

### 4. 文档入口检查

- 打开 `docs/README.md`
- 确认可以找到路线图与执行文档入口

### 5. 目录边界检查

- 确认 `workflows/` 内仅存放示例工作流
- 确认 `storage/` 不再被当作默认权威数据目录使用
- 确认 `.logs/`、`.run-logs/`、`.codex-logs/` 属于本地运行日志

### 6. 纯净部署范围检查

- 对照 `docs/roadmap/week-1-baseline-governance.md`
- 确认纯净部署版不包含日志、缓存、上传文件、生成文件与构建产物

## 通过标准

只有在以下条件全部满足时，Week 1 才视为通过：

- 自动检查全部通过
- 文档入口可用
- 目录边界定义清晰
- 纯净部署范围清晰
